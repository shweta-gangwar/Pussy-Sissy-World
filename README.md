STYLE & MOOD GALLERY

This folder contains the self-contained gallery website.

GitHub Pages setup:
1. Create or open a public GitHub repository.
2. Upload index.html and README.txt to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.

The gallery includes 36 embedded photos, a working search bar, captions, and download links
